# ToDo downloads

**ToDo** is the reminder app you talk to. Say what needs doing and Todo sets the task and the reminder.

## ToDo for Windows

**[⬇ Download the latest version](https://github.com/freelzz/todo-releases/releases/latest/download/ToDo-Setup.exe)**

### Installing

Windows may show **"Windows protected your PC"** the first time you run the installer. That happens because ToDo is a new app that isn't code-signed yet. It isn't a virus warning.

1. Click **More info**
2. Click **Run anyway**

ToDo installs in a few seconds and opens. Sign in with the same account you use on your phone or the web.

### Using it

- Press **Ctrl + Shift + Space** anywhere and say a reminder.
- ToDo waits in the tray (by the clock) and starts with Windows.
